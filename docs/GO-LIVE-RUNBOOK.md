# KidGuard — Runbook เตรียมขึ้นใช้งานจริง (Soft-launch 1–2 ห้อง)

สถานะ: ร่างเฟส 7 · ผู้รับผิดชอบหลัก: เจ้าของระบบ + ผู้ดูแลโรงเรียนกรุงเทพคริสเตียน

## 0. ข้อค้นพบจากการตรวจเฟส 7 ที่ต้องตัดสินใจก่อน go live

| # | เรื่อง | ผลกระทบ | ข้อเสนอ |
|---|---|---|---|
| 1 | **ฐานข้อมูลยังไม่มี backup / PITR** (ตรวจผ่าน Management API ไม่พบ backup) | ข้อมูลหายแล้วกู้ไม่ได้ — **บล็อกการขึ้นใช้งานจริง** | อัปเกรด Supabase เป็นแผนที่มี daily backup + เปิด PITR ก่อนลบข้อมูลสาธิต |
| 2 | Supabase Realtime จำกัดผู้ใช้พร้อมกัน **200** (`max_concurrent_users`) | ผู้ปกครองทุกคนเปิดซ็อกเก็ตพร้อมกันจะเต็ม | ระบบออกแบบให้เปิดซ็อกเก็ตเฉพาะครู/เจ้าหน้าที่/นักเรียน/ผู้ปกครองที่กำลังมีเซสชันรับ; ที่เหลือถามลายเซ็นทุก ≤60 วินาที — ถ้าโรงเรียนใหญ่กว่านี้ให้ขอเพิ่มโควตา |
| 3 | ยังไม่ได้ตั้ง SMTP ของ Supabase Auth | อีเมลยืนยัน/ลืมรหัสผ่านถูกจำกัดอัตราส่งต่อชั่วโมง | ตั้ง SMTP ของโรงเรียน (เช่น Resend/SES) หรือปิดการยืนยันอีเมลตามนโยบายที่ตกลง |
| 4 | นโยบายความเป็นส่วนตัว/ข้อกำหนด เป็น **ร่าง** | ข้อกำหนด PDPA | ให้ DPO/ที่ปรึกษากฎหมายของโรงเรียนทบทวน แล้วแก้ที่ `src/lib/i18n/messages/privacy.ts` และเพิ่ม `PRIVACY_VERSION` |
| 5 | ทดสอบบนมือถือจริง/LINE in-app/GPS ในรถ ทำจากที่นี่ไม่ได้ | ความเสี่ยงหน้างาน | ใช้ checklist หัวข้อ 3 |
| 6 | บัญชีทดสอบรหัสผ่านเดียวกัน (`Test!234`) | ความเสี่ยงถ้าเปิดค้างบน production | ใช้เฉพาะโรงเรียนสาธิต และ **ลบก่อน go live** (หัวข้อ 5) |

## 1. ลำดับก่อนขึ้นใช้งานจริง (ติ๊กตามลำดับ)

1. [ ] เปิด backup/PITR ของ Supabase และทดลองกู้ลงโปรเจกต์ทดสอบหนึ่งครั้ง
2. [ ] ตั้ง SMTP และทดสอบอีเมลยืนยัน/ลืมรหัสผ่านถึงกล่องจริง
3. [ ] ให้ DPO ทบทวนนโยบาย/ข้อกำหนด; เจ้าของตั้งผู้ติดต่อด้านข้อมูลส่วนบุคคลในหน้าตั้งค่าโรงเรียน
4. [ ] ตั้ง `GOOGLE_ROUTES_API_KEY` + `ETA_DAILY_CAP` (เพดานค่าใช้จ่าย) และตั้ง budget alert ที่ Google Cloud
5. [ ] ตั้ง LINE Login/Messaging API ของโรงเรียน (Admin → ตั้งค่า) แล้วทดสอบส่งการ์ดถึงมือถือจริง
6. [ ] ตั้งค่าโรงเรียนจริง: พิกัด ระยะ check-in เวลาเลิกเรียน ประตู/โซน
7. [ ] **ลบข้อมูลสาธิตทั้งหมด** (หัวข้อ 5) และตรวจว่า `select count(*)` ของตารางหลักเป็นศูนย์/มีเฉพาะข้อมูลจริง
8. [ ] สร้างลิงก์เชิญ super_admin/admin จริง แล้ว **ปิดบัญชีทดสอบ**
9. [ ] อบรมครู/เจ้าหน้าที่ (60 นาที — `docs/guides/KidGuard-Training-Handbook.pdf`)
10. [ ] ผู้ปกครองห้องนำร่องสมัครและได้รับอนุมัติ; แจกคู่มือฉบับสั้น

## 2. การทดสอบก่อนเปิด (ทำเองไม่ได้ในสภาพแวดล้อมของผม)

อุปกรณ์จริงอย่างน้อย: iPhone (Safari + LINE in-app), Android (Chrome + LINE in-app), จอใหญ่ที่ประตู (Chrome fullscreen)

- ติดตั้งเป็นแอป (Add to Home Screen) · รับการแจ้งเตือนผ่าน LINE การ์ดจริง
- GPS ระหว่างขับรถจริง 1 รอบ: ปล่อยให้หน้าจอค้างไว้, สลับแอป, สัญญาณหาย → ตรวจป้าย “ไม่อัปเดต” และปุ่ม “ฉันถึงประตูแล้ว”
- เสียงเรียกบนจอประตู (Chrome ต้องแตะ “เปิดเสียง” หนึ่งครั้ง)
- โหลดจริงตอนเลิกเรียน: ดู Supabase → Reports (connections, Realtime) ช่วง 15.00–16.00

## 3. Soft-launch (1–2 ห้อง)

- สัปดาห์ที่ 1: ห้องนำร่อง 1–2 ห้อง ใช้ระบบคู่กับวิธีเดิม (ไม่ยกเลิกวิธีเดิม)
- ทุกวันหลังเลิกเรียน เจ้าหน้าที่กรอกแบบบันทึก (หน้า 4 ของคู่มือฝึกอบรม) + ดูหน้า สถิติ
- เกณฑ์ขยายผล: ผู้ปกครองใช้จริง ≥ 70% ของห้อง · ไม่มีเหตุส่งนักเรียนผิดคน · ครั้งที่ต้องใช้วิธีเดิมแทนระบบ < 5%
- เกณฑ์หยุดชั่วคราว: ส่งผิดคน 1 ครั้ง/ข้อมูลรั่ว/ระบบล่มเกิน 10 นาทีช่วงเลิกเรียน → ใช้ “พักการรับ” + แจ้งผู้ปกครองด้วยวิธีเดิม

## 4. Monitoring และการตอบสนอง

- Vercel: ดู Logs/Errors ของ production; Supabase: Logs, Database → Reports
- Cron `/api/cron/tick` ทุกนาที — ถ้าหยุด ผู้ปกครองจะไม่ได้เตือนรับช้า/หมดอายุเซสชัน; ตรวจที่ Vercel → Cron Jobs
- ตัวแจ้งเตือน: ตั้ง Vercel/Supabase email alerts ถึงผู้ดูแล 2 คนขึ้นไป
- Rollback: Vercel → Deployments → Promote deployment ก่อนหน้า (เฉพาะ production); migration ใช้แบบ forward-only (เพิ่มไฟล์ใหม่แก้)

## 5. ลบข้อมูลสาธิต/ทดสอบก่อน go live

```bash
NODE_USE_ENV_PROXY=1 node scripts/demo-data.mjs --remove
```

สคริปต์ลบเฉพาะโรงเรียนสาธิต (slug `demo-bkc`) และผู้ใช้ `@kidguard.demo` ทั้งหมด รวมข้อมูลลูก (นักเรียน/เซสชัน/การแจ้งเตือน/ไฟล์) — **แถว audit_log ของข้อมูลสาธิตต้องได้รับอนุมัติจากเจ้าของก่อนลบ** (ตามกติกา Audit Trail) ใช้ `--purge-audit` เมื่ออนุมัติแล้ว

หลังลบ ตรวจ: ไม่มีผู้ใช้ `@kidguard.demo` ใน Auth และไม่มีแถว `zz_test_%`/`demo-bkc`
